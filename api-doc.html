网络实习项目 — 后端接口文档

Spring Boot 后端 · 端口 8080 · 数据库 network_internship

服务信息

Base URL http://localhost:8080
前端代理 Vite proxy: /api → http://localhost:8080
数据库   MySQL · network_internship · 127.0.0.1:3306

系统

GET /api/health 200
健康检查，确认服务正常运行。
响应
{"status": "ok"}
GET /api/test/db 200
测试数据库连接，查询 test_table 返回所有记录。

任务一/二 — 协议演示

GET /api/protocol/steps 200
获取 ARP 协议交互步骤列表。
GET /api/protocol/encapsulation 200
获取协议数据封装演示数据（四层头部字段及 payload）。

任务三 — 知识体系 (CRUD)

GET /api/knowledge/layers 200
获取全部五层 TCP/IP 模型信息及各自的知识点列表。
路径参数
无
响应示例
[
  {
    "id": "application",
    "name": "应用层",
    "functionText": "为用户应用程序提供网络服务...",
    "protocols": ["HTTP", "DNS", "FTP", "SMTP"],
    "devices": ["Web 服务器", "DNS 服务器"],
    "dataUnit": "报文 Message",
    "points": [
      {
        "id": "1",
        "title": "HTTP",
        "category": "协议",
        "summary": "超文本传输协议...",
        "detail": "HTTP 基于请求-响应模型..."
      }
    ]
  }
]
POST /api/knowledge/layers/{layerId}/points 201
在指定层下新增一条知识点。
路径参数
layerId — 层标识: application | transport | network | datalink | physical
请求体
{
  "title": "HTTPS",
  "category": "协议",
  "summary": "安全的 HTTP 协议",
  "detail": "HTTPS 在 HTTP 与 TCP 之间加入 TLS..."
}
PUT /api/knowledge/layers/{layerId}/points/{pointId} 200
修改指定知识点。
路径参数
layerId — 层标识
pointId — 知识点 ID (数字)
请求体
{
  "title": "TCP",
  "category": "协议",
  "summary": "面向连接的可靠传输协议",
  "detail": "TCP 通过确认、重传、滑动窗口等机制保证可靠性。"
}
DELETE /api/knowledge/layers/{layerId}/points/{pointId} 204
删除指定知识点，成功返回 204 No Content。
路径参数
layerId — 层标识
pointId — 知识点 ID (数字)
